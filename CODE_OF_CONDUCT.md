# Code of Conduct

CodeTwin ML welcomes thoughtful, respectful contributions from developers, researchers, testers, and security professionals.

## Expected behavior

- Be respectful, constructive, and specific in technical discussions.
- Critique code and ideas rather than attacking people.
- Welcome contributors with different backgrounds and experience levels.
- Respect privacy, attribution, intellectual property, and responsible vulnerability disclosure.
- Keep reports and reviews focused on reproducible evidence.

## Unacceptable behavior

Harassment, discrimination, threats, intimidation, personal attacks, sharing someone's private information without permission, and intentionally disruptive behavior are not acceptable.

## Scope

This code applies to project issues, pull requests, reviews, discussions, and other project-related collaboration spaces.

## Reporting and enforcement

Report conduct concerns privately to repository maintainers through an appropriate private GitHub contact channel. Do not post personal details or sensitive evidence in public issues. Maintainers may remove abusive content, close discussions, restrict participation, or take other proportionate steps.

Security vulnerabilities should instead be reported under [SECURITY.md](SECURITY.md).
